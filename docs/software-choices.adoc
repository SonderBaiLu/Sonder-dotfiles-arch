= 软件取舍

装机和往 DEPS 加东西之前先看这页。原则：桌面服务 noctalia 一家提供，功能不重复；仓库里不留死软件痕迹。

== 现役

[cols="1,2"]
|===
|类目 |选择
|合成器/外壳 |Hyprland（原生 Lua 配置）+ noctalia
|终端 |alacritty-smooth-cursor-git
|shell |fish（tide 提示符、catppuccin 主题、fisher 管插件）
|编辑器 |Neovim —— NvChad 定制版（弃 LazyVim）；另有 helix/nv 配置在仓库
|文件管理 |nautilus（SUPER+E）
|输入法 |fcitx5 全家桶
|通知/锁屏/Polkit/启动器 |noctalia 内置
|资源监视 |Mission Center（Ctrl+Shift+Esc）
|壁纸 |awww（swww 改名，官方 extra 仓库）+ wallust 取色
|浏览器 |Firefox（prime-run 挂独显）
|音频 |PipeWire 栈
|字体 |Noto CJK + emoji
|驱动 |nvidia-open-dkms
|截图 |noctalia 内置（WIN+SHIFT+S）
|远程控制 |Sunshine + Moonlight（WireGuard 中转，见 xref:remote-desktop.adoc[]）
|夜间模式 |hyprsunset（MOD+N）
|播放器 |VLC（软解修复入库）；mpv 可对照
|本地 AI |ollama（用户服务）+ 本地 qwen（8080，另一套）
|连点器 |tools/rightclick（Rust + evdev uinput，SUPER+L / SUPER+R 开关）
|===
